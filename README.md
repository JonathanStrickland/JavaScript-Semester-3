App Name: Password Generator


The purpose of this application is to generate a random password

How to use it:

    To run the app use "node PasswordGen.js"

    Helpful commands are 
        node PasswordGen.js --help
        node PasswordGen.js --length <number>
        node PasswordGen.js --uppercase
        node PasswordGen.js --numbers
        node PasswordGen.js --symbols

    "node PasswordGen.js --help" will display the help menu with list of commands
    "node PasswordGen.js --length <number>" will generate a password with the specified length
        Ex: "node PasswordGen.js --length 10" will generate a password with a length of 10 characters
    "node PasswordGen.js --uppercase" will add uppercase letters to the password
    "node PasswordGen.js --numbers" will add numbers to the password
    "node PasswordGen.js --symbols" will add symbols to the password

To experment run:
    node PasswordGen.js --length 10 --uppercase --numbers --symbols

Output should look similar to this:
    Generated Password: *VbGBFh43%
